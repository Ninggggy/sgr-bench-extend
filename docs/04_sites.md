# 原有网站的探索策略与新题方向

本轮以正式50底题的14个domain字段为索引，按CFPB两个领域合为一个生态、KEGG两个领域合为一个生态，得到与论文12生态相容的工作映射。它是流水线组织方式，不改动原数据字段。以下候选均为设计构想，没有编造新oracle或已测难度。

## 优先级与升级点

| 生态 / 旧底题数 | 现有较强参照 | 下一步探索的升级结构 | 必须排除的假难度 |
| --- | --- | --- | --- |
| WQP / 5 | waterquality_004/005 | 站点→活动→测量字段的身份汇合；活动覆盖与采样条件推翻站点级资格，再回查替代者 | 简单多加characteristic组；把同Activity当完整站点访问；把API视为作弊 |
| Water Office / 5 | wateroffice_005 | 初筛站点产生可比较窗口，窗口内完整性再决定站点组合；缺失见证改变相邻站点选择 | 同一固定窗口再多查几个站 |
| CFPB / 7 | consumerfinance_014/011 | 历史分类映射先决定人群，再在并行口径下独立重算峰值；差异触发上游人群回查 | 把投诉量当因果效应；再重复一次删除循环 |
| CompTox/ChemExpo / 4 | comptox_013 | 区分上层直接归属与后代产品，按产品身份、分类方法和来源文档重算分支赢家 | 将文档出现次数当产品数；假定页面展示全部多重归属；依靠隐藏接口 |
| Census / 4 | census_004 | 从变量定义/人群分母选择表格，跨版本地理/类别映射后重新判资格，输出稳定与翻转组 | 单次全量导出后纯计算；把不同人口宇宙直接比较 |
| NVD / 3 | nvd_002/004 | 由历史事件决定产品候选，再区分CPE名称、范围和AND/OR适用条件；替代映射改变受影响集合 | 增加更多CVE清单；把缺失字典项断言为不受影响 |
| KEGG / 4 | genome_004/003 | 由低层模块/受体证据发现异常分支，回到共同上层寻找可比较姐妹分支，再按原记录身份排除假对应 | 纯药物常识问答；无依据推断“缺失即不存在” |
| Reptile Database / 5 | reptile_003/004 | 名称回查分叉后重新并合历史标本链，正确区分同名不同type与同type多次名称迁移 | 预先列出最终物种；只查已知详情页 |
| Europe PMC / 5 | europemc_004/005 | 多年份不同统计单位（试验/药物/适应证）间的身份分裂/合并，后续证据触发回查原表 | 仅增加一篇PDF；整篇静态表已含最终答案 |
| arXiv / 4 | arxiv_004 | 根据版本史识别事件，再查不同版本的类别/正文/出版线索，回查补齐被别名搜索遗漏的候选 | 只改时间范围；凭题名列出著名论文 |
| NOAA CAG / 2 | climategov_012 | 一个区域/季节的源站查询结果决定后续比较窗口，随后区域口径或基期核对改变候选 | 固定窗口多变量阈值；把异常值和绝对值混作复杂性 |
| CDC WONDER / 2 | wonder_004 | 按官方可发布性与分母要求选择可比较分组，再切换正确出生/死亡口径验证排序 | 推断被抑制数值；将未公开数据当0；人为制造不可回答 |

来源组成不是唯一平衡目标。还应覆盖“初始状态建立、后续状态保持、身份连接、回查修正、完整性证明”几类操作，避免所有新题都变成CFPB式groupby。

## 本轮核对到的机制与限制

- **WQP**：网页表单与服务共享过滤参数；站点、活动、结果和年度汇总是不同粒度。ActivityIdentifier在组织内唯一，但现场测量与采集水样可以是不同Activity，同活动不能自动等同一次完整站点访问；跨活动连接须有来源依据，不能仅按同站同日拼接。旧界面与WQX 3.0对新USGS数据的覆盖存在差别，须记录实际profile。窄结果profile提供ResultIdentifier及检测限连接，是否适用仍要核对实际响应。[WQP服务文档](https://www.waterqualitydata.us/webservices_documentation/)、[用户指南](https://www.waterqualitydata.us/portal_userguide/)、[EPA概念定义](https://www.epa.gov/waterdata/concepts-and-definitions-storage-and-retrieval-and-water-quality-exchange)
- **Water Office**：官方服务可按多个站点、flow/level和时间范围取日均值，亦有月度和极值接口；HYDAT提供包含站点与历史水文资料的Access/SQLite单文件下载。适合检查“网页可用性状态—实际记录”一致性，不能把月均数存在当作每天都有记录。下载路径已有官方说明支持，尚未取得当前数据库或核验其与网页的版本一致性。[官方服务说明](https://wateroffice.ec.gc.ca/services/index_e.html)、[HYDAT说明](https://www.canada.ca/en/environment-climate-change/services/water-overview/quantity/monitoring/survey/data-products-services/national-archive-hydat.html)
- **CFPB**：官方公开API和全部/过滤数据下载；历史产品/issue分类更新也有记录。因此跨分类任务必须指明以原始申报类别还是规范化类别为准，不靠直觉改标签。[投诉数据库与分类说明](https://www.consumerfinance.gov/data-research/consumer-complaints/)
- **Census**：官方定义数据的地理与vintage维度，支持数据发现与地理服务。具体变量跨年是否可比仍需逐项查表，不由生成模型自行假设。[API指南](https://www.census.gov/data/developers/guidance/api-user-guide.html)
- **KEGG**：官方API区分find/get/conv/link及BRITE、module、genome等对象，可将层级探索与标识连接分开验证；能力存在不代表每类具体数据可用或允许批量再分发。[KEGG API](https://www.kegg.jp/kegg/rest/keggapi.html)
- **ChemExpo**：官方指南说明General Category筛选仅返回未分配到更细层级的产品，完整覆盖须枚举后代；页面仅显示产品置信度最高的PUC归属，不能假定可恢复全部竞争归属。PUC的Chemicals表Count是化学物在文档中出现的次数，不能替代产品数；一个组成文档可关联多个产品。已打开化学物页面，动态产品表仍待实际枚举，尚未验证赢家变化。[化学物检索指南](https://comptox.epa.gov/chemexpo/static/user_guide/explore_chemicals.html)、[产品与PUC指南](https://comptox.epa.gov/chemexpo/static/user_guide/explore_products.html)、[数据概览](https://comptox.epa.gov/chemexpo/static/user_guide/data_overview.html)
- **Reptile**：已打开现有入口，具体名称回查行为仍待执行。[Reptile入口](https://reptile-database.reptarium.cz/advanced_search)
- **WONDER**：官方明确被抑制项不按真实隐去数值排序，具体抑制规则因数据集而异。候选只能使用公开值和公开状态，不试图反推出被保护的数值。[WONDER说明](https://wonder.cdc.gov/wonder/help/faq.html)
- 本轮NVD开发页返回空内容，Europe PMC服务页返回403，NOAA/arXiv部分文档入口读取失败。已有旧题可用于形成假设，但这些站点的新机制需后续直接验证；检索摘要不作为已核验原始证据。

## 详细构想A：站点有记录，是否能形成同次监测面板

**自然需求**：为历史河段比较选择能提供共同监测面板的参考站，避免把不同日期/不同介质的测量拼成一次完整监测。

**候选流程**：先在有限河段和历史窗口取得所有符合站点类型的候选；核对组织、ActivityIdentifier、介质、深度和结果身份，明确任务针对单一活动还是有官方关联依据的多活动面板。对每站连接指定测量并验证必要采样条件，检查每个目标季节的完整活动覆盖；再确定相邻比较关系与并列规则。若初选赢家仅在站点年度汇总上符合，回到候选集中寻找替代者并重算相关比较。

**现有切片的边界**：TCEQMAIN-10580在1978年的四指标共现观察保留，但原始响应全部为Other，且同活动可有多个同名结果。Temperature, sample有12条deg C和10条deg F；TCEQMAIN-42838的电导率为150/156 umho/cm，pH为7.1/7.5，相关深度为空，记录均为Final/Actual。当前响应没有ResultIdentifier，不能据此擅自择首、平均或声明每活动唯一数值。它目前只支持名称共现诊断；数值题须补齐来源明确的身份、方法与多值处理依据。见[原始响应](../research/wqp_result_1978_probe.response)与[原有共现分析](../research/wqp_probe_analysis.json)。

**预期输出**：3—8行的站点/比较组、有效活动数量、最早完整活动、被推翻候选及决定性缺失字段；不预填真实站号或计数。是否把诊断字段纳入最终答案要依据研究用途，避免纯粹暴露内部测试逻辑。

**相对waterquality_004/005的提升**：旧题主要是站点层面若干组起止年份汇合；新题要求在活动身份和采样条件上共同成立，而且资格变化影响下游选择。这个差异必须由真实数据展示，若所有组刚好都在同批活动出现，候选没有实现预期升级。

**攻击**：使用官方summary和批量结果下载直接求解；若单个现成导出已经完整表达所需状态，且少量代码就稳定解出，应调低预期难度或换候选，不能禁该解法。

## 详细构想B：由数据决定比较窗口，再决定站点组合

**自然需求**：为相邻水文站选择可复用的历史季节比较面板，报告最后可比站点及失去可比性的首个边界。

**候选流程**：在限定河段和候选年份全集中，先依据Flow而非Level数据确定上游参考站可用的完整月份组合；组合选择采用事先写明的规则。随后验证下游候选站在这些共同窗口的真实日数据覆盖。若某站无法满足完整性要求，按题目业务规则选择替代窗口/相邻比较组，并重新检查受影响站点。回查轮数必须有限并有确定停止条件。

**可替代的自然窗口假设**：用同一上游参考站各年指定季节的日均Flow最大值日期确定观察窗口，再核验下游逐日覆盖。须预先定义参考季节完整性、并列峰值取最早日期、峰值前后天数、跨月/跨年日期展开、有效日记录及标记的纳排规则；下游不能改用各自峰值窗口。共同覆盖年份再决定最终站点组合。这是资料可用性候选，尚未找到使赢家变化的真实切片，也不推断洪水传播关系；日均峰值不能换成瞬时极值。[官方服务说明](https://wateroffice.ec.gc.ca/services/index_e.html)

**相对wateroffice_005的待验证提升**：旧题的1966/1967及5—9月事先给定；新构想的比较窗口由先前公开证据决定，并与站点资格耦合。但窗口未知不代表必须取得前序结果后再检索：有限候选站和年份的全季日数据可能预先批量取得。不能用没有业务意义的任意递归规则强造难度。

**先行攻击**：先验证多站日均服务或HYDAT能否覆盖全部所需字段与日期，再尝试预取全季数据、本地求峰值与窗口、核验覆盖并排序。若成功，只能据实际过程评价集合维护与口径判断难度，不能再声称多轮自适应检索不可替代；若只剩简单计算，则更换构想。不得为了保住构想而禁用原协议允许的官方批量下载。此攻击尚未执行，详见[站点复核](../research/site_review_2026-09-08.md)。

**真实见证要求**：至少存在一个年跨度看似通过但逐日检查失败的站，且会改变最终比较组；若页面完整月与日数据存在矛盾，应先解决数据口径，不选“网站错误”作为谜题。

## 详细构想C：历史产品分类与投诉队列的共同口径

**自然需求**：在一次历史分类修订前后，比较同一种金融服务问题的投诉集中月份，避免分类变化伪装成群体变化。

**候选流程**：先从官方历史分类文件确定一个服务概念在两个时期的可比较类别范围；只在定义可明确对齐时继续。按各时期原始标签提取有限队列，分别核对纳排差异；以第一队列的实际高频问题定义后续分层，再独立重算第二队列与公共可比子集的峰值、州和公司，解释某个表面赢家为何在共同口径下被替换。

**相对consumerfinance_014的提升**：014已有三轮数据驱动删除，不能再用更多删除轮次当创新。新题的核心应是有官方依据的历史类别映射与并行人群状态保持。若类别映射必须主观猜测、或所有数据下载后变成简单改名groupby，淘汰该候选。

## 详细构想D：完整层级覆盖与来源证据改变用途分支

**自然需求与流程**：为少量化学物整理某用途范围内的产品覆盖与组成证据。先区分General直接归属产品与后代节点产品，完整枚举层级；再按公开产品身份连接分类方法和来源文档，依预先声明的证据要求重算代表分支。分类方法纳排须服务于研究用途，产品数和独立组成文档数须分别定义。现有ChemExpo-B的“同产品多类别归属”假设由此替换，不要求恢复页面未展示的归属。

**相对comptox_013的提升与见证**：013主要独立选择历史推荐路径和当前最大计数路径；新方向要求层级覆盖改变产品集合，来源核验进一步改变分支选择。必须找到只查General、混用文档/产品计数或忽略分类方法会改变最终赢家的真实见证；完整公开下载仍是合法解法。尚未取得产品全集或新oracle，若只增加聚合计算则淘汰。[化学物检索指南](https://comptox.epa.gov/chemexpo/static/user_guide/explore_chemicals.html)、[产品与PUC指南](https://comptox.epa.gov/chemexpo/static/user_guide/explore_products.html)

以上构想都尚未定题。首轮探索的任务是找到支持这些结构的真实切片；找不到就记录失败，不能先固定目标答案后回填证据。
