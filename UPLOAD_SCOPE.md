# GitHub upload scope

This repository intentionally preserves the reusable construction system and
the substantive benchmark artifacts, rather than every execution byproduct.

Included:

- complete construction code, documentation, prompts, schemas, runtime, and
  protocol;
- each selected task's final substantive revision, including prompts, oracle,
  rules, reference computation, evidence indexes, verification, and audit
  conclusions;
- official delivery, audit, and bounded-retrieval retest summaries;
- three representative failure cases from the 31-task retest: incomplete
  arXiv scope, a zero-score NVD result, and an unscored WQP result.

Excluded:

- raw downloads, source captures, sessions, event/tool logs, recovery inputs,
  and candidate snapshots;
- ordinary historical runs and repeated implementation copies;
- stderr, CLI dumps, per-run input copies, ledgers, and transient exploration
  material.

The exclusions only affect Git tracking. All local files remain in place.
