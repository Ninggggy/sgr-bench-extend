# r03 参考答案与独立核验

运行solve_reference.py会从同revision的原始官方响应重建完整数据，再计算每个独立单活动撤回。辅助panel_reference.py和initial_state/independent_check.sql负责重建并交叉核验原始面板/窗口；最终independent_check.sql从独立wide来源重建833个撤回情景及全部输出，不读取主程序情景分类或oracle。

全部833情景纳排见scenario_ledger.jsonl；所有支持改变情景的区间判定见trial_window_ledger.jsonl；独立SQL情景结果见independent_trial_decisions.jsonl；12行最终结果见oracle.psv和独立产生的independent_answer.psv；216字段的逐项证据在private/field_evidence.jsonl；具体剩余候选和被选记录见selected_activities.json。原始站点460条和主干17站纳排沿用同次重算保存的candidate_universe/inclusion_ledger，不能将只出现于最终答案的两种撤回站点当成全部候选。

此切片中5个活动撤回改变完整前沿，共3种不同后续状态。全833情景分类及216字段经不同SQL路径完全一致；另一个四参数代码导出与指标名称导出逐字段一致，详见independent_pcode_check.json。HTTP错误原文保留且不用于推断不存在记录。

参考程序无关键活动、获胜窗口、最终测量或行数硬编码。它证明在保存源记录和明确任务条件下答案可重算；不证明模型难以答对，也不替代后续独立审计、难度对照或人类专家判断。
