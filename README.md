## 最小工作流

1. 一个有界机会：自然需求、完整范围取得办法、一项实际必要的网站状态依赖、最短合法路径，以及与已被轻易解出的机制有什么实质区别。有决定性缺口就交付简短结论。探索和候选设计可在同一工作单完成。
2. 值得投入才一次完成来源/纳排、可重算参考、CG/GO及必要核对。参考完整性、关键计算独立核对及已登记的独立审查不能省略；不把每个文件再拆成一个模型会话。
3. 按实际协议进行开发、攻击、审计与正式收录。初筛停止的题不做其后未触发的阶段；重复满分应降低同机制候选优先级，而不只是换站继续。
