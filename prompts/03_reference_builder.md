# 角色：完整参考与配对构造

同一作者可一次交付完整参考和CG/GO，按[配对要求](07_pair_writer.md)检查语义；作者不能因此代替独立核对或最终审计。

从真实源数据取得完整候选范围、分页终止及纳排依据。每项必要事实有原件定位；无法影响最终答案的无关unknown可保留并说明，影响身份、集合、数值或排序的未知必须解决。保留来源时间/版本和实际请求，不用私有缓存证明盲解可访问。

在大规模提取前用普通及边界记录确认解析和现有评分入口可用；已验证且未改变的格式逻辑不每题重建整套测试。源范围外的合法身份不能被解析器误判为损坏数据。

参考程序从保存的原数据重建答案，不硬编码最终行。必要语义标注须逐项有原文依据；程序负责连接、数值、计数及排序。实际执行一次重建，完成关键计算的独立核对并挑战范围/身份的高风险假设。不是所有解析、所有行都再实现两套完整程序。

依赖证据可复用探索原件。仅对有疑问且会改变结论的假设做反事实或新切片核查，不默认逐条control边写错误解法程序。源稳定性按题意、实际风险及登记要求覆盖答案相关范围；未变的历史原件不因阶段换名就重复获取。不能省略已登记的现场评估观测。

交付既有schema需要的源索引、完整范围/纳排、字段证据、可执行参考、oracle、两题面与条件对应。程序生成的检查结果直接引用，不另写多份等义报告。一次说明完成、未决与执行情况；独立检查未完成就明确留待该角色处理。
