## 4. 在正式求解前准备评分器

先查找可复用的真实评分实现，核对其规则；不能从历史汇总分数、已接受字段或旧分子重建本次得分。缺少可用实现时，只实现本题所需的最小评分器。

依据正式题目的 rubric 规范化，按不带版本后缀的 arXiv ID 对齐行。支持题面允许的表格表示，不因 Markdown 表格外壳直接判零。保留原始作答及解析过程，不补缺失字段、不改事实、不依据 gold 选择更有利的重复行，也不排序预测后再算顺序分。

按论文计算：
- Item-F1 = 2 × 正确字段数 /（gold字段总数 + pred字段总数）。
- Row-F1 = 2 × 全字段正确行数 /（gold行数 + pred行数）。
- P.O.A. = 共同ID中相对顺序正确的行对比例；共同ID少于2个时按论文记0，并注明原因。

输出原始计数、分母、未匹配ID和逐字段差异，不能只有三个分数。重复ID、缺字段、空答案及解析失败须有明确处理与状态，不能悄悄丢行。语义别名只采用有依据的明确规则；不能用模型自由判断给分。若只能完成严格匹配版本，明确标为暂定评分，未验证的语义等价单列，不宣称论文完整评分已复现。

用独立的3行×3字段手算样例验证：完全正确时三个指标均为1；仅逆序时F1不变、P.O.A.=0；删除一行时两种F1为0.8；仅错一个非ID字段时Item-F1=8/9、Row-F1=2/3；空预测为0。再检查 Markdown/竖线表的等价解析及重复ID不能重复领分。样例明确标为人工测试数据，不能充当模型作答。评分规则在查看本次作答前确定，评分器故障修复后对同一原始答案重新计分并记录修改。
