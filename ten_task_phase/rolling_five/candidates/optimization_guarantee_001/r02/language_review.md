Ambiguity checks considered two plausible readings and their consequences:

- Complete bullet versus its opening citation pair: the latter omits two cited works. Both prompts explicitly include the continuation to the next bullet.
- Bibliography entries versus distinct original works: these yield four rows versus three. Both prompts require established work-identity deduplication.
- Original title version versus latest version at the survey posting: this can change the selected source. Both prompts restrict old title versions to identity evidence and state the inclusive posting cutoff.
- Any related nonconvex result versus one reproducible main statement: a later method with inexact updates can produce a different locator. Both prompts select the first relevant main-text theorem in document order and the nonconvex part where needed.
- Any randomness versus sampled-loss randomness: this changes the fixed-function work's query category. The shared output definition distinguishes random sensing directions from sampled loss values and excludes classification by a noiseless special case.
- Algorithm output versus theorem quantity: this changes last-iterate interpretations and, for the random-index statement, the iterate endpoints. Both prompts explicitly preserve the gap-to-iterate shift and prohibit replacing the reported operation with a last-iterate quantity.
- Expectation of a minimum versus minimum of expectations: these are different random quantities. The category definition puts expectation outside the minimum.
- Repaired expected-objective gap versus the paper's printed gap symbol: these would make different mathematical assertions where F/f notation is inconsistent. Both prompts explicitly request the paper-denoted gap without correcting its definition. The reference reports that limitation; no private rule substitutes f for F.
- Unresolved evidence versus a negative claim or deleted row: these change the output set. Both variants retain rows, use UNKNOWN for missing cells, provide a citation fallback identity and prohibit NONE.
