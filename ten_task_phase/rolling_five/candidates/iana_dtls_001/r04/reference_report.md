The reference CLI uses only standard-library Python and captured sources plus independently checked semantic event annotations. Run from any directory:

`python3 /absolute/path/to/r04/reference.py --out-dir /absolute/path/to/r04/rebuilt`

The optional `--source-dir` defaults to r04/sources. It enumerates every registry record, parses all full History events while removing duplicate snippets, requires annotation coverage of the exact observed event set, derives replacement from RFC text, derives review identity/date/value from event text, and sorts qualifying reviews by timezone-aware event time.
