# Design rationale

Natural goal: determine the registration-level molecular identity support of a finite diazepam Ki cohort before receptor-subtype grouping, while exposing explicit subunit-description incompatibilities and engineered-receptor labels. It does not estimate drug effects or assert statistical pooling eligibility.

The preferred-name record boundary is explicit and verified by a complete official name query. The B/Ki/nM/= standard-field slice matches the intended registered affinity inventory, with no threshold or post-result winner selection. Non-literature data, related compounds and alternative endpoint types are outside this stated registry audit. Retained duplicate/validity flags and original pKi/unit conversions demonstrate that scope is not silently narrowed to apparently clean measurements.

The at-least-one required logical dependency is activity-derived assay selection: default activity descriptions lack direct-versus-homologous assignment. The actual cohort includes both even when explicit human receptor compositions are written in the description. Target component relationships substantiate the defined-complex/group/single distinction; the linked CBR publication supplies a genuine abbreviation resolution. All are finite activity-conditioned identities rather than whole-database scans.

Old comparison 1: chembl_stereochemical_peers_001/r02 enumerated 16 connectivity-related compounds and classified stereo specification. It used structural search state and returned32fields; both raw developmentA results were full but had access-protocol issues. The present target-attribution question is not that task renamed, and no old scores are reused. Present output is11rows/22fields; size itself is not a hardness claim.

Old comparison 2: chembl_indexed_discovery_assays stopped because its known compound/paper default activity+paper-assay package covered minimum comparisons. This cohort is a different drug and source-wide registered affinity audit; activity results expose59papers and126assays. H/D cannot be recovered from the default activities or determined by a single task-known paper. Do not require an extra dependency shape beyond the actual activity→assay step.

Old comparison 3: assay_variant_sequence_identity sought actual experimental constructs and failed on scope/construct evidence. This candidate explicitly asks about registered attribution and description compatibility, not construct reconstruction. Single-subunit registrations, unknown origins, mutant/chimeric descriptions and broad groups remain limited evidence rather than assumed wild type. No optional accession column or actual-effect conclusion was added.

Shortest observed-source reference path: identify source/release and preferred-name compound, retrieve one complete activity page, one selected-assay response, one selected-target response, and the actual CBR paper metadata when needed. Sources and version definitions are two further small metadata reads, reusable within the workflow. Full database export was not tested and is not presumed unavailable. Scientific boundary errors are hypotheses for the unchanged A protocol, not a prediction of a sub70 score.

The source-neutral release37/May2026 descriptor is copied from the previously approved open-discovery repair, including the distinction between database prepared date and release issue date. Source discovery is intended by Method; no website name, URL, ID prefix or answer identity is exposed in public instructions.

Full remaining validation: independent pre-A content review; CG/GO A and if justified B; attacks2; final quality review1; six formal runs. Constructor output does not complete any of those model/human stages.
