## 通过：原件覆盖与事件语义

`iana_reconciliation_reference/history.html` 为 151447 字节完整 HTML，含闭合事件表和闭合 html；从 2017-12-27 草稿族首次上传至 2024-01-26，共 170 个唯一事件，没有分页或待加载后续事件标记。独立 HTMLParser 按真实 tr/td 结构提取，得到相同的 170 行、每行四列，全部 action 正文与作者 events.json 的规范化文字相同；13 个 snippet 都有对应 full 正文。正文是在 HTML 中已经存在的完整内容，不能把网页视觉折叠误说成必须另发请求才能取到。

semantic_review.json 的 170 项标注与原 HTML 事件一一对应。本审查逐项读了所有短动作，并另读所有长正文；关键词分类只用于组织材料。结果为：

- **唯一纳入**：`history-800636`（HTML 1724–1730 行），2021-03-26、rev 10、Sabrina Tanamal。正文直接表明是主管方完成的审查，第二项行动明确计划更新 temporary connection_id 的 Value: 53、Reference: RFC-to-be；结尾明确是获准出版后才执行的计划。
- **11 条主管方行政状态排除正确**：包括 2021-04-16 `history-803525` 的 IANA OK - Actions Needed，以及六月 Action 状态。它们不包含明确拟议编号，不能充当更晚的实质提案。
- **5 条相关长评论排除正确**：`history-804344` 是其他评议者的 by/from IANA 语法建议，`history-803932` 是关于 53 不兼容性的提问；`history-720243`、`history-719779`、`history-689758` 明确是 shepherd 文书，相关段落是其自行检查登记事项，并非主管方自己的分配审查。
- 其余 153 条是版本上传、评议、会议、流程和非主管方评论。即使含“assignment”也可能是给审稿人分派工作；未发现另一条主管方拟议 ExtensionType 的实质正文。

“完整”的边界是该官方草稿族 History 展示的事件与全文，不是全部站外邮件、线下审查或所有 RFC 标签事件。这里 public 所求是规范形成过程中的正式文档历史审查，且要求受审草稿身份；不能扩张成“最后一次所有形式的 IANA 活动”。未来若重写成这种更宽的问题，当前 170 事件就不能直接声称闭合新范围。

## 通过：最新 CG/GO、来源发现及 SGR 路径

最新 paired_draft.json 的 CG、GO 共享条件后缀逐字相同：范围日期、16 位 ExtensionType、独立数值、DTLS-only=Y、deprecated 名称、明示替代、发布前最后一条主管方自己的实质提案、日期与完整受审版本、五列、排序、NONE 和 UNRESOLVED。CG 额外说明发现引用后选择对应文档族历史视图的步骤；没有改变纳排或答案条件。

**Method:12 的不直接揭示网站条件在当前草稿中通过。** 题面没有直接给出 IANA、Datatracker 品牌或网址，也没有提供 RFC9146、草稿族、53/54、审查日期等答案定位值。TLS ExtensionType 是规范确定的协议字段空间，负责它的登记主管方是明确角色，不是随意“某个数据库”。保留这些必要领域语义能唯一界定注册范围和审查主体，未像直接删除 ChEMBL 品牌那样把注册身份全集变成任意数据库；也没有加入来源谜语。CG 对“document-history view”的过程提示符合 CG 提供检索逻辑的定位，不等于直接给出网站。

SGR 的证据不只是引用跳转：注册结果确定定义规范，已有 `iana_followup_evidence.json:E1` 的官方 RFC 默认文档记录明确给出对应草稿族；随后需配置该发现族的 History 视图。原 HTML 736–764 行实际呈现同一文档的 Status、评议、writeup、History 控件，1038 行附近区分 RFC 与草稿历史，1724 行以后才是回答历史计划的证据。默认规范文本只有最终登记结果，没有这条审查日期、受审版本与当时计划。因而在 Datatracker 内存在由发现的规范族身份确定后续历史视图的真实依赖；本地排除、取最后项和表格拼接不另算检索依赖。

一次获得完整正确族 History 的批量响应属于合法结果驱动检索，不因它能离线重算就自动失去 SGR 性质。也不能把视觉展开按钮列为不可绕过的额外依赖，因为原 HTML 已带完整正文。
