# Source-first construction review

The Nature Medicine seed identifies GSE145926 as its own dataset and GSE128033 as borrowed healthy-control input. Choosing the latter changes the later Europe PMC ACCESSION_ID query. The saved official result for the correct series and specified publication interval contains all 14 hits in one page; every full XML is saved. The May 8 Viral-Track paper is outside the explicitly later interval, not silently omitted.

The legal Europe PMC API supports a complete accession/date/open-PMC cohort and fullTextXML downloads. These downloads are allowed and encouraged; the task does not rely on hiding the API. Saved source receipts include the actual requests and successful responses. Repository records are publicly accessible through NCBI GEO SOFT, the EBI BioStudies study API and the EBI PRIDE project API. The solver's existing official-read tool admits their hosts; no new paid service or tool restriction is introduced.

The 14 paper XML files alone contain an actual provenance counterexample. PMC7577733's resource table labels both GSE141634 and GSE152586 as “This paper.” Its data statement also groups them before the explicitly reused inputs. Following GSE141634 to GEO yields a different linked PMID (32661339), whose identity record gives an earlier journal publication. That earlier Nature Cell Biology article actually reports the same experimental organoid deposit. GSE152586 instead links to the candidate's PMID 33128895. The later retrieval therefore removes one plausible answer pair while preserving the other. The public conditions explicitly require this distinction; no hidden prior-publication criterion is used.

The source-conditioned path is seed identity → complete indexed reuse cohort → each paper's experimental deposit identities → repository publication identity → a different earlier paper when indicated. Local extraction and sorting are not counted as retrieval dependencies. Full fixed paper downloads do not include the different earlier paper or the repository provenance records. A legal bulk strategy covering those further sources is not prohibited, and the subsequent shortcut attack must assess whether it collapses the dependency in practice. This is a construction argument pending independent Astra audit, not a certified SGR result.

The reference program extracts accession pairs from source-checked experimental-deposit clauses, then applies the checked earlier-publication exclusion. candidate_pool.json records all 14 semantic inclusion/exclusion judgments and original XML paragraph locators. These judgments are manual Astra construction annotations; the program does not pretend that domain judgments follow from a keyword match. A separate DOM traversal and repository-linked publication comparison independently reconstructs four provisional pairs, excludes GSE141634, and matches the three-row answer. Both programs have run successfully. Content validation and difficulty remain unvalidated until the required audit and blind runs complete; no human expert validation is claimed.
