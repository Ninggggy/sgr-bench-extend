# Public retrieval policy — 2026-09-19

Use public web search, ordinary webpage fetch/read (including native web open), normal navigation, identity indexes, individual records and individual original documents. Blind solving does not require a browser plugin. Browser-plugin reproducibility validation belongs to the construction side and is not a blind tool prerequisite. Normal page loading of scripts/data is not a direct data-API call by the solver. Reading one original PDF is permitted.

Do not use large-scale fetch, crawling, database/site exports, complete substantive candidate-data downloads, prejoined necessary answer information, or split requests intended to accomplish the same bulk acquisition. Do not directly query data APIs (including REST, GraphQL, SPARQL or OGC endpoints), download/SQL MCP tools, or private construction material. Ordinary webfetch is permission to read pages, not permission to query data interfaces.

Normal search/list pagination is allowed: at most 20 requested entries per page and 10 pages per logical query. If page size is not selectable, use and report the site's normal default page size. Local reasoning/calculation on legitimately read material is allowed; this does not authorize additional tools.

There is no per-trial external-request cap or experimental external-request concurrency cap. Record actual usage and failures. Follow actual tool security requirements. Do not access prior answers, private evidence, construction browser history or other trials. Report inaccessible evidence and partial answers honestly. Access, parsing and format failures are distinct from content mistakes.
