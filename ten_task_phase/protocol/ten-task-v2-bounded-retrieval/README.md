# 有界检索盲测协议 v2

用户已授权禁止完整批量导出。本版仅改变获取规则；模型、评分、日期、镜像、原阶段账本/截止及双面各3次严格低于70%的收录要求保留。工具和评分文件继续引用v1原件，v1目录、旧题面和所有历史试次不修改。

规则见 [retrieval_policy.md](retrieval_policy.md)：统一每页20条（无可选大小时允许普通默认页并记录）、同一逻辑查询10页、会话60个外部请求项、同时2个请求项。数字是测试前的初始实验设置，尚无适用性或效率验证，不按题目成绩调整。构造前必须证实在这些限制下存在完整合法路径；不可靠耗尽额度或来源故障制造低分。完整发现候选身份的正常索引分页与整套实质数据批量导出分别判断。

实施为运行时强制注入公开规则，加独立轨迹审核；不是网络层硬拦截。native web不能由本地下载器统一计数或封锁，仍可能产生违规请求。评分器保留原始分数，收录器要求每个正式试次的 retrieval_review.json 通过，缺失/不合规不收录、不补零。请合并到已有访问审查，不额外创建模型角色。

审查文件包含 run_id、protocol_version、verdict，以及 checks 下 bulk_scope、query_dependencies、pagination、request_count、concurrency、safety 六项；每项写 verdict、explanation、evidence_paths（相对此运行目录的真实非空轨迹文件）。解释中列出实际请求数、分页数和最大并发，并指明轨迹行号及默认分页例外。文件存在检查不等于审核内容自动正确，不冒称人工审核完成。

所有后续开发/攻击/正式试次统一用本版。原开发计划的v1记录保留；新计划须显式登记v2，禁止将v1开发/正式成绩混入v2。旧高分版本不因协议变更自动重抽。现有题面的宽泛bulk许可由注入规则覆盖；新题面应直接写明遵守实验获取规则，避免矛盾。
